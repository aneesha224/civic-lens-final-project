# Group B additional McCarthy speeches

This batch contains eighteen complete public remarks from archived official Speaker.gov pages. The HTML replays are preserved in `captures/`; the text files contain the speech or remarks only, with surrounding page text excluded. Some pages label the block “Remarks as prepared”; others introduce the complete text directly. The event setting and transcript boundaries were checked against each source. All eighteen records have also been merged into `data/campaign_speeches/manifest.csv` and its captures folder.
