# Rick Scott 2012 and 2014 State of the State addresses

Two additional complete address transcripts are staged from public text sources. WPBF's January 10, 2012 page reproduces the full address from Scott's opening greeting through his closing blessing. Governing's 2014 page reproduces the full speech from the opening greeting through “Thank you.” The reader-rendered source pages are preserved in `captures/`; the 2014 PolitiFact capture corroborates the March 4 delivery date (Governing published the text the next day).

CSV paths are relative to this batch folder. Both record IDs and source URLs were absent from the canonical manifest when staged.
