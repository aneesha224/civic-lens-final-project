# AWPC speech batch

Contains 36 newly verified, complete speech transcripts from the Archives of Women’s Political Communication at Iowa State University. The archive is speaker-filtered; each original page and source text extract is preserved in `captures/`.

All record IDs and speech dates were checked against the curated manifest at staging time. We excluded existing events, duplicate DNC text, multi-speaker items that could not be isolated, interviews, press conferences, congressional floor speeches, and records below 250 words. These rows are staged only; the central manifest was not edited.

The CSV schema matches `data/campaign_speech_records.csv`. `transcript_path` is relative to this batch folder and should be remapped under `data/campaign_speeches/captures/` when merged.
